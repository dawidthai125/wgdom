## 1. Zasady wiążące (kontynuacja)

Principles **#001–#007** z NG-04.2 pozostają obowiązujące. NG-04.3 rozszerza **#007** o ATH metadata.

### 1.1 NG-04 Principle #007 — Presentation Metadata Only (ATH)

> Już wiążące od 2.63.10 — **bez zmian semantyki**.

- Tooltipy ATH, confidence, source labels → **derived cache**, nie `KosztorysBoqRowViewModel`.

### 1.2 NG-04 Principle #008 — ATH Fidelity is Explain, Not Re-parse

> **WIĄŻĄCE** od NG-04.3.

| Reguła | Znaczenie |
|--------|-----------|
| **Explain in place** | BOQ wyjaśnia stan komórki ATH (priced / no value / no match) |
| **Full fidelity elsewhere** | Pełny code, przedmiar, R/M/S → **JobFilePreviewModal** (istniejący) |
| **No merge bloat** | `buildKosztorysBoqExplorerView` **nie** woła `parseKosztorysBytes` |
| **No snapshot write** | NG-04.3 nie zapisuje do KV nowych pól |
| **Session preview optional** | Ewentualny cache `AthPreviewResult` — **poza MVP 04.3**, wymaga osobnego audytu pamięci |

```text
KosztorysBoqRowViewModel + dossier meta (read-only)
              │
              ▼
   buildBoqAthPresentationCache()     ← pure, NIE ViewModel
              │
              ▼
   BoqAthTooltip / BoqAthSourceChip   ← UI adapters (#006 pattern)
              │
              ▼
   KosztorysBoqRowFields (ATH columns)
```

### 1.3 NG-04 Principle #009 — Explain Before Expand

> **WIĄŻĄCE** od NG-04.3.

Hierarchia UX — **kolejność obowiązkowa** (od najlżejszej do najcięższej):

| Krok | Warstwa | Co użytkownik dostaje |
|------|---------|------------------------|
| **1** | **Tooltip** | Wyjaśnienie komórki ATH (priced / FOUND_NO_VALUE / no match) — bez nawigacji |
| **2** | **Source chip** | Typ dokumentu, confidence, skrót pliku — kontekst źródła |
| **3** | **CTA** | Tekstowy link w BOQ („Szczegóły źródła ATH”) — bez otwierania modala automatycznie |
| **4** | **Modal ATH** | `JobFilePreviewModal` — pełna tabela, code, przedmiar, R/M/S — **tylko na akcję użytkownika** |

**Zakazy (#009):**
- Otwarcie modala ATH przy wejściu na tab Kosztorys lub przy search/filter
- Duplikat pełnej tabeli ATH w BOQ Explorer (kopiowanie wierszy z modala)
- Wywołanie `parseKosztorysBytes` / `fetchAndParseKosztorys` z BOQ w celu „wzbogacenia” UI
- CTA „Pełny podgląd” **przed** wdrożeniem tooltipów (kolejność implementacji)
- Drugi niezależny modal ATH poza `JobFilePreviewModal`

**Implementacja CTA:** reuse istniejącego handlera `TenderKosztorysWorkspace` → `JobFilePreviewModal` (jeden punkt wejścia).

## 2. Model derived — `BoqAthPresentationMeta`

```typescript
// src/lib/tender-kosztorys-boq-ath-presentation.ts (propozycja)

export type BoqAthCellState =
  | "priced"           // athUnitPrice present
  | "no_value_doc"     // FOUND_NO_VALUE (document-level)
  | "no_match"         // catalog row, brak ATH row match
  | "empty_priced_row" // matched but unitPrice empty (edge)

export interface BoqAthPresentationMeta {
  athCellState: BoqAthCellState;
  tooltipPl: string;
  knrHint: string;           // z row / extractKatalogHint — read pass-through
  knrHintSource: "description";
}

export interface BoqAthDocumentMeta {
  sourceType: CostDocumentUiType;
  sourceFilename: string;
  confidenceLabel: string | null;  // bucket z costDiscovery.confidence
  pdfCaseLabel: string | null;     // pdfPrzedmiarCase 1/2/3
  explainCta: "open_ath_preview";
}
```

**Zakaz:** pól powyższych na `KosztorysBoqRowViewModel`.

## 3. Mapowanie tooltipów (freeze)

| `athCellState` | Warunek | Tooltip (PL) |
|----------------|---------|--------------|
| `priced` | `athUnitPrice` | Opcjonalnie: „Cena jednostkowa zamawiającego (ATH)” |
| `no_value_doc` | `resolvedCostStatus === FOUND_NO_VALUE` | „Przedmiar bez cen — dokument zawiera ilości bez wyceny inwestora.” |
| `no_match` | `!athMatched` + FOUND_WITH_VALUE lub catalog bez ATH | „Brak dopasowania pozycji w snapshot ATH (lp/opis).” |
| `empty_priced_row` | `athMatched` && !athUnitPrice | „Pozycja ATH bez ceny jednostkowej w pliku.” |

**UI:** ikona `ⓘ` lub dashed underline na „—”; Radix Tooltip — reuse shell.
